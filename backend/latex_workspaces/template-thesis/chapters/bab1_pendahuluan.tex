\section{Pendahuluan}
\label{sec:pendahuluan}
Menulis dokumen ilmiah berukuran besar seperti skripsi, tesis, atau disertasi sering kali menjadi tantangan jika seluruh teks disimpan dalam satu file tunggal. Pendekatan modular memisahkan dokumen ke dalam bab-bab terpisah (\texttt{chapters/}), konfigurasi (\texttt{preamble/}), dan gambar (\texttt{assets/}).

\subsection{Manfaat Struktur Modular}
Beberapa manfaat utama struktur modular:
\begin{itemize}
    \item \textbf{Fokus Kerja:} Penulis dapat fokus mengedit satu bab tanpa terdistraksi isi bab lainnya.
    \item \textbf{Pencegahan Konflik:} Mempermudah kolaborasi dan pelacakan versi menggunakan Git.
    \item \textbf{Performa Editor:} Editor teks seperti AegisResearch bekerja lebih responsif dan ringan.
\end{itemize}

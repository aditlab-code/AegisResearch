# Catatan Riset & Panduan Menulis Tesis

## Panduan Cepat Struktur Dokumen
1. **File Utama (`main.tex`)**: Berperan sebagai Root Document yang merangkai seluruh dokumen.
2. **Sub-direktori**:
   - `chapters/`: Naskah bab-bab penelitian terpisah.
   - `assets/`: Tempat menyimpan gambar, bagan, dan plot figur (PNG, JPG, PDF).
   - `preamble/`: Konfigurasi paket dan metadata dokumen.
   - `frontmatter/`: Lembar pengesahan dan abstrak.
   - `backmatter/`: Lampiran dan dokumen pendukung.
3. **Kompilasi**: Tekan tombol **Compile** (`Ctrl+B`) di AegisResearch untuk membuat `main.pdf`.

\section*{Lampiran: Cheatsheet Shortcut LaTeX}
\addcontentsline{toc}{section}{Lampiran: Cheatsheet Shortcut LaTeX}
Berikut adalah jalan pintas (keyboard shortcuts) penting saat menulis di AegisResearch:
\begin{itemize}
    \item \texttt{Ctrl+B}: Kompilasi Dokumen Utama ke PDF secara otomatis.
    \item \texttt{Ctrl+S}: Simpan perubahan file aktif ke subfolder.
    \item \texttt{Alt+J}: Sinkronisasi kursor editor ke tampilan PDF (Forward SyncTeX).
    \item \texttt{Ctrl+Click} (pada PDF): Lompat langsung ke baris kode editor (Inverse SyncTeX).
\end{itemize}

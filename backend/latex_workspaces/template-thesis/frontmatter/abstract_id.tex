\section*{Abstrak}
Dokumen ini merupakan template dan panduan praktis penulisan karya ilmiah berbasis LaTeX modular. Dokumen mencakup tata kelola pemisahan bab, pengelolaan aset gambar pada folder \texttt{assets/}, penulisan persamaan matematika, serta manajemen sitasi otomatis menggunakan engine BibLaTeX dan Biber.

\vspace{0.5em}
\noindent\textbf{Kata Kunci:} LaTeX, Tesis Modular, BibLaTeX, Biber, AegisResearch.

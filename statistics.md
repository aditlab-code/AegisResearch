### T-Test

#### Independent Sample T-Test : student, welch, Mann-whitney

1. Alternative Hypotesis:
    1.) Group 1 =/ Group 2
    2.) Group 1 > Group 2
    3.) Group 1 < Group 2
2. Missing Value
    1.) Exlude cases per dependent variable
    2.) Exlude cases listwise
    
> Assumption Check Normality
    
#### Paired Sample T-Test : Student, Wilcoxon signed-rank

1. Alternative Hypotesis:
    1.) Measure 1 =/ Measure 2
    2.) Measure 1 > Measure 2
    3.) Measure 1 < Measure 2
    
2. Missing Value
    1.) Exlude cases per dependent variable
    2.) Exlude cases listwise
    
> Assumption Check Normality

#### One Sample T-Test : Student, Wilcoxon signed-rank, Z-test

1. Alternative Hypotesis:
    1.) =/ Test Value
    2.) > Test Value
    3.) < Test Value
    
2. Missing Value
    1.) Exlude cases per dependent variable
    2.) Exlude cases listwise
